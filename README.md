# Data_Analysis_Dashboard
Interactive Power BI dashboard analyzing the Data Analyst job market (Jul 2025–Jul 2026) — tracking postings, salaries, top skills, work-type split, and hiring locations.

🧭 Overview

This dashboard provides a data-driven view of the Data Analyst job market, helping job seekers, recruiters, and analysts understand:

How many jobs were posted and their average salary
Which skills are most in-demand
How salary varies by seniority level
The split between Remote, Hybrid, and Onsite roles
Posting trends over time
Which cities have the most job openings

🔑 Key Metrics (KPI Cards)
->Metric	Value
->Total Job Postings	600
->Average Salary	$85K
->Remote %	30.50%
->Hybrid %	42.17%

📈 Dashboard Features
1. Filters / Slicers
   Seniority Level: Entry, Mid, Senior
    Work Type: Hybrid, Onsite, Remote
2. Top Skills Requested
   Horizontal bar chart ranking the most frequently requested skills, led by SQL and Excel, followed by Google Analytics, Power BI, Python, Azure, and Looker.
3. Average Salary by Seniority
   Column chart comparing average salaries across Senior, Mid, and Entry level roles — showing a clear upward trend with seniority.
4. Work Type Split
   Donut chart breaking down postings by Hybrid (42.17%), Remote (30.50%), and Onsite (27.33%).
5. Postings by Month
   Area/line chart tracking the volume of job postings over the 12-month period, highlighting overall market demand trends.
6. Top Locations by Postings
   Bar chart ranking cities with the highest number of job postings, led by Raleigh and Atlanta.



🛠️ Tech Stack
       Tool: Microsoft Power BI
       Data Processing: Power Query (data cleaning & transformation)
       Visualization: Power BI native visuals (bar, column, donut, area charts, cards, slicers)
